## REMOVED Requirements

### Requirement: Per-challenge content lives in a dedicated challenge folder
**Reason**: Replaced by single `challenges.json` file. Challenge data no longer resides in individual `challenges/challenge-<id>/` directories. The server extracts needed files to `.java-runtime/challenges/` at runtime.
**Migration**: Migrate all challenge data from `challenges/challenge-*/challenge.json`, `prompt.md`, `starter/Solution.java`, and `tests/visible-tests.json` into the consolidated `challenges.json` file at the project root.

### Requirement: Each challenge folder exposes the required challenge assets
**Reason**: Subsumed by `challenges.json` schema. Starter code, test cases, and metadata are fields in the JSON rather than separate files.
**Migration**: The `challenges/` directory structure is replaced by the single `challenges.json` file. The `.java-runtime/challenges/` directory is auto-generated by the server for Java compilation.
